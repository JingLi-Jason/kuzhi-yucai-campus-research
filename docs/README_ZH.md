# 项目阅读说明

本项目保存桂阳县苦志育才公益学校的调研资料、分析数据、建筑设计图纸和研究成果。目录与文件名统一采用英文，原始中文回答、访谈转写和原始文件内容保留原文。

## 先看哪些文件

- `outputs/paper/`：最新英文 Word 论文，约 3,850 词，包含词云、统计结果、参考文献和完整附录。
- `outputs/portfolio/`：最新英文 15 页可编辑 PPT 与 PDF。
- `outputs/companion/`：中文论文及作品集等配套版本。
- `data/processed/`：问卷、词频、环境审计、活动观察和作息分析数据。
- `data/transcripts/`：访谈文字与时间片段转写。
- `raw/`：原始问卷、录音、照片、地图和建筑 PDF。
- `figures/`：论文图、词云和设计图纸，可单独取用。

## 文件关系

调研原始资料 → 转写与逐题整理 → 词频、环境评分和活动分析 → 英文论文与校园设计作品集。

`docs/DATA_GUIDE.md` 解释主要数据表。`docs/file_manifest.csv` 记录英文路径、原始文件名和校验值，便于找回对应材料。目录命名变化不改变原始资料的含义。

`src/verify_project.py` 检查文件完整性；`src/recount_keywords.py` 从中文回答重新计算词频。`src/legacy/` 保留历史制作脚本，其中 `${ORIGINAL_WORKSPACE}` 等占位符表示原制作环境路径，完整排版脚本运行前需要配置环境。

全部材料包含校园照片与访谈录音，因此完整归档使用私有仓库。旧报告放在 `archive/`，最新英文论文以 `outputs/paper/` 为准。
